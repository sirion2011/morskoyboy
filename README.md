# ⚓ Морской бой — Telegram Bot

Telegram-бот для игры в классический «Морской бой» на aiogram с рефералами, жизнями, сложностью и премиумом.

---

## 🎮 Возможности

- Полноценная игра с компьютером (расстановка кораблей, пошаговые ходы)
- 3 жизни + возможность получить дополнительные
- Реферальная программа (бонусы за приглашённых друзей)
- 3 уровня сложности (лёгкий, средний, сложный)
- Премиум-доступ с расширенными возможностями
- Профиль игрока со статистикой
- Планировщик задач для напоминаний

---

## 🛠 Технологии

- Python 3.11
- aiogram 3.x (асинхронный фреймворк для Telegram API)
- Tortoise ORM
- MySQL
- asyncio
- python-dotenv
